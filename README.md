# The AI Timeline — by PUJIVERSE

An interactive history of artificial intelligence, from Ada Lovelace's first algorithm (1843) to the models released in September 2026.

**A PUJIVERSE project.** Data as of September 29, 2026.

## What's inside

- **Timeline** — 1843 → 2026 on a glowing center line, in nine eras (research on the left, products on the right).
- **Release Tracker** — 130+ releases from 2022 to today, in list or calendar view, filterable by company, type and open vs. closed, with same-day clashes highlighted.
- **Coming Soon** — announced, reported, rumored and cancelled releases, each with its source.
- **Model Library** — 100+ model pages with lineage, change logs (new / fixed / removed), specs, and side-by-side comparison.
- **AI Tools & Websites**, **Pioneers**, **AI Winters**, **How AI Is Generated** (with a tokenizer demo), **Companies** and **Models Today**.
- **AI Guide** — a built-in chatbot that answers from the site's data. It runs on Claude when the page is opened on claude.ai; elsewhere it shows a notice instead of answering.

## Run it

It's one self-contained file. Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → deploy from the `main` branch) to host it.
